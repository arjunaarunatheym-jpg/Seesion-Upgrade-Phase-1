2. EXACT PROFORMA WARNING PROPAGATION LOGIC
-------------------------------------------
    proforma_summaries = []
    for pf in proformas:
        snap = self._compute_invoice_snapshot(
            pf,
            payments_map.get(pf.get("id"), []),
            cn_map.get(pf.get("id"), []),
        )
        proforma_summaries.append({
            ...audit-only fields...
            "net_invoiced_value": 0.0,   # DELIBERATELY 0
            "outstanding_amount": 0.0,   # DELIBERATELY 0
        })
        warnings.extend(snap["integrity_warnings"])

    Guarantees:
      * Proformas contribute ZERO to gross_invoice_value, credit_note_total,
        net_invoiced_value, paid_amount, outstanding_amount, overpayment_amount,
        and session_revenue.
      * A clean proforma (no payment, no active CN, no unknown-status CN)
        does NOT emit any new session-level warning.
      * A proforma with an attached active payment DOES surface exactly one
        NON_ELIGIBLE_INVOICE_HAS_ACTIVITY warning at the session level.
      * A proforma with an attached unknown-status Credit Note DOES surface
        UNRECOGNIZED_CREDIT_NOTE_STATUS at the session level while leaving
        the underlying CN record untouched.
      * The session-level PROFORMA_UNLINKED_MATCH / MULTIPLE_ACTIVE_PROFORMAS
        codes are NOT emitted by _compute_invoice_snapshot(), so no
        duplication is possible.
