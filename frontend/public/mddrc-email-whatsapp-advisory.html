1. Email Integration

1.1 How It Works

Your system already generates events (invoice issued, session created, payment received, certificate ready). The integration hooks into those events and auto-sends formatted HTML emails with attachments (e.g., invoice PDF, certificate PDF).

1.4 DNS Verification Steps

  1. Sign up at resend.com
  2. Add your domain mddrc.com.my
  3. Resend will give you 2-3 DNS records to add (TXT records for SPF/DKIM)
  4. Add those records in your domain registrar (e.g., GoDaddy, Namecheap, etc.)
  5. Wait 5-30 minutes for DNS propagation
  6. Click "Verify" in Resend dashboard
  7. Done - you can now send emails from @mddrc.com.my

2. WhatsApp Integration

2.1 Options Comparison

Option A: Click-to-Send Links (Free)

  • Zero cost, zero setup
  • Generates wa.me/60xxx?text=... links
  • "Send via WhatsApp" button next to invoices, certs, reminders
  • Opens WhatsApp with pre-filled message
  • Not automated - someone clicks to send
  • Best for: quick start, manual follow-ups

Option B: Twilio WhatsApp API (Paid)

  • ~RM 0.15-0.30 per message
  • Fully automated - no manual clicks
  • Requires Facebook Business verification (1-2 weeks)
  • Pre-approved message templates only
  • Professional sender identity
  • Best for: high volume, full automation
